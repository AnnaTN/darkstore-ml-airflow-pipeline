# ML-пайплайн прогнозирования продаж дарксторов с мониторингом стабильности признаков в Apache Airflow

Эффективность компании, являющейся новой сетью дарксторов и специализирующейся на быстрой доставке продуктов и товаров повседневного спроса, критически зависит от качества управления запасами. 

Специфика онлайн-доставки не позволяет клиентам заменять отсутствующие товары аналогами, что при дефиците приводит к отмене заказа и потере лояльности. Текущее ручное планирование закупок не справляется с оптимизацией запасов, вызывая три ключевые проблемы: упущенную выручку из-за дефицита, финансовые потери от списания излишков и общую операционную неэффективность бизнеса.

Задача в рамках проекта — создать полноценный ML-пайплайн для прогнозирования продаж по батч-признакам. Он должен включать:
1. Обучение модели на исторических данных с мониторингом стабильности признаков с помощью PSI.
2. Сохранение артефактов модели в S3.
3. Реализацию пайплайна в инференсном срезе признаков в Airflow с загрузкой данных из Postgres и записью результатов обратно.


## Логика обучения

Данные были разделены по времени:

- обучение: февраль 2023 г. - август 2025 г.;
- валидация: сентябрь - октябрь 2025 г.

Использована модель `CatBoostRegressor` с гиперпараметрами:

- `random_state` = 42;
- `early_stopping_rounds` = 200;
- `use_best_model` = True;
- `verbose` = 200.

Качество модели оценивалось по метрикам MAE, RMSE и R². Полученные результаты:

- `MAE` — около 1394;
- `RMSE` — около 2929;
- `R²` — около 0,98.

Стабильность признаков оценивалась с помощью PSI. Признаки с PSI ≥ 0.2 были исключены: `temperature`, `fuel_price`, `factor1`, `factor2`, `factor4`, `cpi`, `unemployment`, `year`. Признаки `month` и `quarter` сохранены для учёта сезонности, несмотря на высокий PSI.

## Архитектура пайплайна

DAG включает следующие задачи:

- `load_data` - объединяет таблицы `sales`, `plan`, `stores` и `features` из PostgreSQL во временную таблицу `inference_data_temp`;
- `preprocess_features` - обрабатывает данные, создаёт временные, лаговые, агрегированные признаки и отбирает строки датафрейма;
- `load_model` - загружает обученную модель catboost_model.pkl из S3;
- `run_inference` - выполняет пакетное прогнозирование и обрабатывает отрицательные прогнозы;
- `save_predictions` - записывает результаты в таблицу `predictions` в PostgreSQL.

Источником данных являются таблицы из PostgreSQL. Модель хранится в объектном хранилище S3 Yandex Cloud. Подключения и секреты настраиваются через Airflow Connections и Variables.

## Инструкция по запуску

1. Установить зависимости:
```
pip install -r requirements.txt
```

2. Создать файл .env с параметрами подключения к PostgreSQL и S3:
```
DB_NAME=
DB_HOST=
DB_PASSWORD=
DB_PORT=
DB_USER=

S3_ACCESS_KEY_ID=
S3_SECRET_KEY=
S3_BUCKET=
```

3. Запустить все ячейки `model_training.ipynb`. Модель будет обучена и сохранена в `S3` под ключом `catboost_model.pkl`.

4. В Airflow создать Connection `postgres_sales_db` с параметрами PostgreSQL.

5. Создать Airflow Variables:
```
s3_access_key = 
s3_secret_key =
s3_bucket_name = 
s3_model_key = catboost_model.pkl
```

6. Убедиться, что файлы batch_inference_dag.py и preprocessing.py находятся в одной папке dags.

7. В интерфейсе Airflow найти DAG `sales_prediction_batch_inference` и нажать Trigger DAG.

8. После успешного выполнения проверить результаты с помощью SELECT-запроса.
